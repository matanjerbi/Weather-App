# אטמוספרה — אפליקציית מזג אוויר שמלמדת

**להתקנה:** [Releases → latest → Weather.apk](../../releases/latest)

## מה יש
- **מפה חיה**: רוח (חלקיקים זזים), טמפרטורה, גשם, עננים, לחץ ואיזוברים עם H/L, מכ״ם חי, משבים, לחות, נקודת טל, ראות, UV, CAPE, גובה האפס, 850/500 hPa, זרם הסילון, גלים, טמפרטורת הים ולוויין אינפרא-אדום. סליידר של 5 ימים עם הפעלה אוטומטית, כפתור "?" שמסביר כל שכבה, ונגיעה בנקודה במפה מציגה את כל הנתונים שלה.
- **תחזית**: מצב נוכחי, התראה על גשם בשעה הקרובה, כרטיס "למה היום ככה?" שמחבר את הנתונים של היום למושג (שרב, שקע קפריסאי, אפיק פרסי ועוד), 48 שעות בגרף, 7 ימים ופרטים עם הסבר לכל נתון.
- **מצב אופנוע**: ציון רכיבה לכל שעה וחלונות הזמן הכי טובים היום ומחר.
- **מעבדה**: דיאגרמת Skew-T עם מצב מוסבר (בסיס ענן, היפוכים, CAPE, גובה האפס, דגלוני רוח) והשוואה בין המודלים ECMWF, GFS ו-ICON, כולל מדד הסכמה לכל יום.
- **ללמוד**: 23 שיעורים בארבעה שלבים, כל אחד עם מבחן קצר. שיעורים פותחים שכבות מקצועיות במפה. יש גם מילון מונחים ו"חזאי היום": מנחשים את מחר ומתחרים במודל.
- **התראות** (גשם מתקרב, משבים, חום, שרב) ו**ווידג'ט** למסך הבית.

## איך זה בנוי
- `app/src/main/java/...`: מעטפת אנדרואיד (Kotlin): ‏WebView, גישה למיקום, WorkManager להתראות, וווידג'ט.
- `app/src/main/assets/www`: כל הממשק (JS נקי + Leaflet).
- נתונים: Open-Meteo (חינמי, בלי מפתח API), RainViewer, EUMETSAT, CARTO/OSM.
- `node tests/run.mjs`: בדיקות ללוגיקה (איזוברים, תרמודינמיקה, ציון רכיבה, כללי ההסבר, השיעורים).
- כל push ל-`main` בונה APK ומפרסם אותו ב-Release בשם `latest`.
